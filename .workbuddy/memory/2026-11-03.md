### Hei 「假播放」疑点已排除（重要）
`total=10792943` 在 tx/kg 出现两次，怀疑接口对任意 id 返回同一样本。逐层验证：
1. 4 个不同 songmid（搜"稻香 周杰伦"）→ total 均 8940938、md5 均 `5fbdfda1…`。**误报**：这是同一首歌的多个专辑版本，后端指向同一份音频。
2. 交叉顺序测试（晴天→稻香→晴天→稻香→晴天）：`10792943/68cd90fb…` 与 `8940938/5fbdfda1…` 严格按 id 切换且可回切。
3. 时长核对：10792943B@321kbps ≈ 4:29 = 晴天实际时长；8940938B ≈ 3:42 = 稻香实际时长。**结论：tx.php 确实按 id 取歌，内容正确，不是假播放。**
4. 非法 id（`ZZZZnotexist`、`ffffffff…`）返回 404 + 409B HTML，说明有 id 校验。
（`curl` 直连该域名全失败/0 字节，必须用 node fetch；排查时注意这一点。）
